# Changelog

All notable changes to HAF are documented in this file.

## [1.1.0] — First Practical Demonstration

### Added

- HAF Quick Start in README
- First complete worked example: HAF Worked Example #001 — From Aviation Safety Data to Safety Intelligence
- Practical demonstration of the eight-step HAF workflow
- Explicit separation of evidence, context, analysis, intelligence assessment, and limitations
- Open community review request through GitHub Issue #1

### Focus

This release strengthens HAF as a practical, reusable methodology rather than adding software or unnecessary complexity.

- Contribution guidelines
